Privacy Policy

Last updated: October 6, 2026

1. Controller and contact

BB Audio Control is developed and provided as an independent software project. Privacy-related enquiries can be directed to the operator and developer through the public GitHub project.

GitHub Issues – BB Audio Control

Please do not publish pairing codes, local IP addresses, computer names, or other confidential or personal information there.

2. General data processing

BB Audio Control does not require a user account and does not use a cloud service operated by the developer. Usage, device, and audio data are not transmitted to the developer for analytics, advertising, or telemetry.

Communication required for the application's features takes place directly between the Windows PC running BB Audio Control and the tablet, smartphone, or other browser device connected by the user on the local network.

3. Information processed and transmitted locally

To provide its control features, BB Audio Control may process the following information on the Windows PC and transmit it to a paired device within the local network:

  • information about running applications and their audio sessions,
  • volume levels and mute states,
  • available and selected audio output and microphone/input devices,
  • media information such as title, playback state and, where available, associated cover or thumbnail artwork,
  • system information displayed in the user interface, such as CPU, GPU and memory information,
  • network and connection information required for the local connection.

This information is used solely to provide the features offered by BB Audio Control on the connected devices.

4. Pairing and local network communication

Access to the control interface is protected by a pairing process using a six-digit code. Communication takes place within the network used by the user.

BB Audio Control currently uses HTTP and WebSocket without transport encryption. The application should therefore only be used on a trusted private network. Use on public or otherwise untrusted networks is not recommended.

5. Local storage

Settings and configuration information required for operation may be stored locally on the Windows PC so that the application's configuration can be retained between launches. BB Audio Control does not transmit these locally stored settings to a cloud service operated by the developer.

6. Telemetry, analytics and advertising

BB Audio Control does not contain developer-operated telemetry or usage analytics and does not display advertising. No usage profiles are created, and application data is not processed or sold for advertising purposes.

7. Disclosure to third parties

BB Audio Control itself does not transmit data processed by the application to the developer or to third parties for analytics or advertising. Apart from update checks, external services may be involved when the user chooses to access them, for example GitHub to download the software, view the project repository, or submit a support request or bug report. Those external services are subject to their providers' respective privacy policies.

From version 1.2.0, the Windows app automatically contacts GitHub at startup and daily to check for stable releases. Manual checks are also available. GitHub receives technically necessary connection data, including the public IP address and the app version in the User-Agent. Pairing PINs, app assignments, audio data and local settings are not sent. Installers are downloaded only after the user chooses Install now. Update check times and postponements are stored locally.

8. GitHub Pages and GitHub

This project website is hosted using GitHub Pages. When the website is accessed, GitHub, as the hosting provider, processes technically necessary connection data in accordance with its own privacy terms. This processing by GitHub is separate from the local data processing performed by BB Audio Control.

9. Changes to this privacy policy

This privacy policy may be updated if BB Audio Control's features or data processing practices change. The current version will be published on this page.
