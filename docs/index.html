1.1.0

Programme direkt vom Tablet starten

Fünf Tasten mit Windows-Icons starten deine Apps oder holen vorhandene Fenster nach vorn. Drei Sekunden halten beendet die zugeordnete App zwangsweise, auch im Hintergrund. Dabei kann ungespeicherte Arbeit verloren gehen.

In der Windows-App den Bereich Programmstarter ausklappen, Apps im Startmenü suchen oder eine Datei auswählen. Name, Namensanzeige und Hintergrundfarbe lassen sich je Taste anpassen. Belegungen bleiben beim Update erhalten.

Die Programmstarter erscheinen nur in der Tabletansicht ab 1107 × 710 CSS-Pixeln. Kleinere Browserflächen verwenden die Smartphoneansicht ohne Startertasten; die Programmlautstärkefader bleiben sichtbar.

Windows kann die Fokusübernahme einschränken. Skripte, Installer und Protokollverknüpfungen lassen sich nicht immer eindeutig einem laufenden Programm zuordnen.

Neu in 1.2.0

Updates direkt in der Windows-App

BB Audio Control sucht beim Start und täglich auf GitHub nach Updates. Du entscheidest: Jetzt installieren oder Später. Über Nach Updates suchen lässt sich die Prüfung auch manuell starten. Downloads werden vor der Installation per SHA-256 geprüft. PIN, Einstellungen und Programmbelegungen bleiben erhalten.

Die Updateprüfung benötigt Internet und verbindet sich mit GitHub. Die Installation startet erst nach deiner Zustimmung.

Lokal im Netzwerk

Dein PC, dein Tablet, keine Cloud

Die Steuerung läuft direkt zwischen deinem Windows-PC und dem Mobilgerät. Ein Pairing-Code schützt vor unerwünschter Bedienung im Netzwerk.

  • Kein externer Cloud-Dienst erforderlich
  • Neuer Pairing-Code trennt bestehende Verbindungen
  • Derzeit HTTP/WebSocket ohne Transportverschlüsselung
  • Nur in einem vertrauenswürdigen privaten Netzwerk verwenden
