Datenschutzerklärung

Stand: 6. Oktober 2026

1. Verantwortlicher und Kontakt

BB Audio Control wird als unabhängiges Softwareprojekt entwickelt und bereitgestellt. Für Datenschutzanfragen kann der Betreiber und Entwickler über das öffentliche GitHub-Projekt kontaktiert werden.

GitHub Issues – BB Audio Control

Bitte veröffentliche dort keine Pairing-Codes, lokalen IP-Adressen, Rechnernamen oder sonstigen vertraulichen bzw. personenbezogenen Daten.

2. Grundsatz der Datenverarbeitung

BB Audio Control benötigt kein Benutzerkonto und verwendet keinen vom Entwickler betriebenen Cloud-Dienst. Es findet keine Übertragung von Nutzungs-, Geräte- oder Audiodaten an den Entwickler zu Analyse-, Werbe- oder Telemetriezwecken statt.

Die für die Funktionen der Anwendung erforderliche Kommunikation erfolgt direkt zwischen dem Windows-PC, auf dem BB Audio Control ausgeführt wird, und dem vom Nutzer verbundenen Tablet, Smartphone oder anderen Browsergerät im lokalen Netzwerk.

3. Lokal verarbeitete und übertragene Informationen

Zur Bereitstellung der Steuerungsfunktionen kann BB Audio Control insbesondere folgende Informationen auf dem Windows-PC verarbeiten und innerhalb des lokalen Netzwerks an ein gekoppeltes Endgerät übertragen:

  • Informationen über laufende Anwendungen und deren Audiositzungen,
  • Lautstärke- und Stummschaltungszustände,
  • verfügbare und ausgewählte Audioausgabe- und Mikrofon-/Eingabegeräte,
  • Medieninformationen, beispielsweise Titel, Wiedergabestatus und – sofern verfügbar – zugehörige Cover- bzw. Vorschaubilder,
  • Systeminformationen, die innerhalb der Benutzeroberfläche angezeigt werden, beispielsweise CPU-, GPU- und Arbeitsspeicherinformationen,
  • für die lokale Verbindung erforderliche Netzwerk- und Verbindungsinformationen.

Diese Informationen dienen ausschließlich dazu, die von BB Audio Control angebotenen Funktionen auf den verbundenen Geräten bereitzustellen.

4. Pairing und lokale Netzwerkkommunikation

Der Zugriff auf die Steuerungsoberfläche wird durch ein Pairing-Verfahren mit einem sechsstelligen Code abgesichert. Die Verbindung erfolgt innerhalb des vom Nutzer verwendeten Netzwerks.

BB Audio Control verwendet derzeit HTTP und WebSocket ohne Transportverschlüsselung. Die Anwendung sollte deshalb ausschließlich in einem vertrauenswürdigen privaten Netzwerk verwendet werden. Die Nutzung in öffentlichen oder nicht vertrauenswürdigen Netzwerken wird nicht empfohlen.

5. Lokale Speicherung

Einstellungen und für den Betrieb erforderliche Konfigurationsinformationen können lokal auf dem Windows-PC gespeichert werden. Diese lokale Speicherung dient dazu, die Konfiguration der Anwendung zwischen Programmstarts beizubehalten. BB Audio Control überträgt diese lokal gespeicherten Einstellungen nicht an einen vom Entwickler betriebenen Cloud-Dienst.

6. Telemetrie, Analyse und Werbung

BB Audio Control enthält keine vom Entwickler betriebene Telemetrie oder Nutzungsanalyse und keine Werbung. Es werden keine Nutzungsprofile erstellt und keine Anwendungsdaten zu Werbezwecken verarbeitet oder verkauft.

7. Weitergabe an Dritte

Durch BB Audio Control selbst werden die von der Anwendung verarbeiteten Daten nicht an den Entwickler oder zu Analyse- oder Werbezwecken an Dritte übermittelt. Zusätzlich zur Updateprüfung können externe Dienste betroffen sein, wenn der Nutzer selbst externe Angebote aufruft, beispielsweise GitHub zum Herunterladen der Software, zum Aufrufen des Projekt-Repositories oder zum Erstellen eines Support- bzw. Fehlerberichts. Für diese externen Dienste gelten die jeweiligen Datenschutzbestimmungen des Anbieters.

Ab Version 1.2.0 verbindet sich die Windows-App beim Start und täglich automatisch mit GitHub, um stabile Releases zu prüfen. Eine manuelle Prüfung ist ebenfalls möglich. GitHub erhält technisch erforderliche Verbindungsdaten einschließlich der öffentlichen IP-Adresse und der App-Version im User-Agent. Kopplungs-PIN, Programmbelegungen, Audiodaten und lokale Einstellungen werden nicht gesendet. Installer werden erst nach der Auswahl Jetzt installieren heruntergeladen. Prüfzeitpunkte und aufgeschobene Hinweise werden lokal gespeichert.

8. GitHub Pages und GitHub

Diese Projektwebsite wird über GitHub Pages bereitgestellt. Beim Aufruf der Website verarbeitet GitHub als Hostinganbieter technisch erforderliche Verbindungsdaten entsprechend den eigenen Datenschutzbestimmungen. Diese Verarbeitung erfolgt durch GitHub und ist von der lokalen Datenverarbeitung innerhalb von BB Audio Control zu unterscheiden.

9. Änderungen dieser Datenschutzerklärung

Diese Datenschutzerklärung kann angepasst werden, wenn sich Funktionen von BB Audio Control oder die Art der Datenverarbeitung ändern. Die jeweils aktuelle Fassung wird auf dieser Seite veröffentlicht.
