# BB Audio Control 1.3.0

## Deutsch

- Neue Einstellungen mit den Reitern **Ausgänge**, **Programme** und **Weitere Einstellungen**. Ausgänge und Programmfader per Drag-and-drop mit Maus oder Touch sortieren; kompaktere Ausgangskacheln und Bedienelemente.
- Wiedergabeprogramm aus den von Windows bereitgestellten Mediensitzungen wählen und einen bevorzugten Player festlegen. Am Titel/Cover per Wischgeste wechseln; die vollständige Auswahl steht unter **Einstellungen → Weitere Einstellungen → Mediensteuerung** bereit. Nicht alle Programme melden Mediensitzungen an Windows.
- Zusätzliche Gerätekennungen helfen, Ausgangsnamen, Farben und weitere Zuordnungen nach Treiber- oder Windows-Updates wiederzuerkennen. Automatische Übernahme nur bei eindeutiger Zuordnung; alte Einstellungen bleiben erhalten und lassen sich bei Bedarf manuell übernehmen.
- Hardwareerkennung im Hintergrund vermeidet zusätzliche vollständige Scans beim normalen Ausgangswechsel.
- PIN, Einstellungen, Programmbelegungen und Autostartwahl bleiben bei Updates erhalten.

Die GitHub-Ausgabe prüft beim Start und täglich auf Updates. Installation erst nach Zustimmung über „Jetzt installieren“; „Später“ verschiebt den Hinweis. Ältere Ausgaben ohne Updater benötigen ein manuelles Update. Store-Installationen werden über den Microsoft Store aktualisiert.

## English

- New settings tabs: **Outputs**, **Programs** and **More settings**. Reorder outputs and application faders by dragging with a mouse or touch; more compact output tiles and controls.
- Choose from media sessions reported by Windows and set a preferred player. Swipe the title/cover to switch; the full picker is available under **Settings → More settings → Media controls**. Some applications do not report media sessions to Windows.
- Additional device identifiers help recover output names, colors and other assignments after driver or Windows updates. Automatic recovery requires an unambiguous match; previous settings are retained and can also be restored manually.
- Background hardware identification avoids extra full scans during normal output switching.
- Pairing PIN, settings, launcher assignments and startup preference are retained during updates.

The GitHub edition checks for updates at startup and daily. Installation requires confirmation using “Install now”; “Later” postpones the reminder. Older editions without the updater require a manual update. Store installations are updated through the Microsoft Store.
