# BB Audio Control 1.3.2

## Deutsch

- GPU-Abfragen laufen in einem getrennten Hilfsprozess derselben Anwendung. Bei einem Treiberwechsel kann dieser neu gestartet werden, ohne die Hauptanwendung durch native GPU-Abfragen zu gefährden; GPU-Werte können kurzzeitig fehlen.
- Die Ausgangshistorie erhält ausgeblendete Geräte und Anpassungen bei eindeutig erkannten neuen Windows-Gerätekennungen. Mehrdeutige Zuordnungen werden nicht automatisch zusammengeführt; verspätete Browser-Einstellungen überschreiben die Wiederherstellung nicht.
- Automatische lokale Diagnoseprotokolle unterstützen die Fehlersuche. Maximal fünf Dateien zu je 1 MiB; keine automatische Übertragung, keine PINs oder Audiodaten.
- PIN, Einstellungen, Programmbelegungen und Autostartwahl bleiben beim Update erhalten. Die Tablet-/Smartphone-Seite danach einmal neu laden.

### Installation und Prüfung

Windows 10 (Build 19041 oder neuer) / Windows 11, x64. Self-contained mit .NET 8; keine separate Runtime nötig. Den Installer über die vorhandene Installation ausführen. Der Installer ist weiterhin unsigniert. Diese Veröffentlichung aktualisiert den GitHub-Vertrieb; kein Microsoft-Store-Release.

Gerätefreie Prüfung: jeweils 58 C#-Tests in Debug und Release sowie 6 Web-Einstellungstests bestanden; Anwendungsbuilds ohne Warnungen oder Fehler. Installation und Konfigurationserhalt wurden lokal geprüft. Der Nutzer bestätigte zwei NVIDIA-Treiberupdates ohne Absturz und weiterhin normalen Betrieb. Andere Hardware- und Treiberversionen sind dadurch nicht vollständig geprüft. Gelegentlich langsamere Audiozustandsabfragen bleiben ein bekannter Optimierungspunkt.

Lokale Protokolle: `%LocalAppData%\BBAudioControl\Logs`. Dateien vor freiwilliger Weitergabe prüfen. Der Anwendungscode bleibt privat; die GitHub-Quellarchive enthalten nur die öffentlichen Projektdateien.

## English

- GPU queries run in a separate helper process of the same application. Driver changes can restart that helper without exposing the main application to native GPU queries; GPU readings may temporarily be unavailable.
- Output history preserves hidden devices and customizations when new Windows device identifiers can be matched unambiguously. Ambiguous matches are not merged automatically; delayed browser preferences cannot overwrite recovery.
- Automatic local diagnostic logs assist troubleshooting. At most five files of 1 MiB each; no automatic upload, pairing PINs or audio data.
- Updates retain the pairing PIN, settings, app assignments and startup preference. Reload the tablet/smartphone page once after updating.

### Installation and validation

Windows 10 (build 19041 or newer) / Windows 11, x64. Self-contained .NET 8; no separate runtime required. Run setup over the existing installation. The installer remains unsigned. This release updates GitHub distribution only, not the Microsoft Store.

Device-free validation: 58 C# tests passed in each of Debug and Release, plus 6 web-preference tests; application builds completed without warnings or errors. Installation and configuration retention were checked locally. The user reported two NVIDIA driver updates without a crash and continued normal operation. Other hardware and driver combinations remain unverified. Occasional slower audio-state queries remain a known optimization item.

Local logs: `%LocalAppData%\BBAudioControl\Logs`. Review files before voluntarily sharing them. Application source remains private; GitHub source archives contain only public project files.
