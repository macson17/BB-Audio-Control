# BB Audio Control 1.2.0

## Deutsch

- Die Windows-App sucht beim Start und täglich auf GitHub nach einer neueren stabilen Version.
- **Nach Updates suchen** ist in den Einstellungen und im Traymenü verfügbar.
- **Jetzt installieren** lädt den Installer herunter, prüft SHA-256 und startet das Update. **Später** verschiebt den Hinweis um einen Tag.
- PIN, Einstellungen, die fünf Programmbelegungen und die Autostartwahl bleiben erhalten.

Die Updateprüfung benötigt Internet. Der Installer ist derzeit nicht digital signiert. Die Steuerung von Audio und Programmen bleibt lokal. Der reale Testwechsel von der lokalen 1.1.1 auf 1.2.0 erfolgt durch den Nutzer; die Versions-, Download-, Prüfsummen- und Windows-UI-Prüfungen wurden separat durchgeführt.

## English

- The Windows app checks GitHub for a newer stable release at startup and daily.
- **Check for updates** is available in settings and the tray menu.
- **Install now** downloads the installer, verifies SHA-256 and starts the update. **Later** postpones the prompt for one day.
- Your pairing PIN, settings, five app assignments and startup preference are retained.

Update checks require internet. The installer is currently unsigned. Audio and program control remains local. The user will perform the real upgrade from local 1.1.1 to 1.2.0; version, download, checksum and Windows UI checks were performed separately.

Windows 10/11 x64. Installer and SHA256SUMS are available in the release assets. Application source code is private; GitHub's automatic source archives contain only this public documentation and website repository.
