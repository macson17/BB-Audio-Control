# BB Audio Control 0.10.0 Beta

Pre-Release / test version — keine stabile oder endgültige Version.

## Neuigkeiten

- Responsive Darstellung für unterschiedliche Tabletgrößen und kompaktes Layout für kleinere/niedrig aufgelöste Tablets.
- Smartphone-Oberfläche im Hoch- und Querformat, ohne CPU-/GPU-/RAM-Anzeige und ohne einzelne Ausgangsbuttons.
- Sound lang: Ausgangsauswahl; Sound kurz: weiterhin stumm/ein.
- Mikrofon lang: weiterhin Mikrofoneingang auswählen.
- Horizontaler Hauptlautstärkefader auf Smartphones und ein Bearbeiten-Menü mit den dort relevanten Funktionen.
- Weiterhin maximal fünf Programme, keine Prozess-ID, globale und individuelle Faderfarben.
- Bestehende Tablet-Bedienung, Pairing/PIN und direkte WebSocket-Steuerung bleiben erhalten.

## Teststatus

Darstellung **nach Nutzerprüfung erfolgreich** auf iPad, iPhone 16 Pro und
Samsung Galaxy S21 Ultra. **TABWEE T80: Betatest noch ausstehend.**
Release-/Installer-Build und isolierte Browserprüfungen bestanden; ein lokales
Upgrade von 0.9.9 erhielt Einstellungen einschließlich PIN. Keine darüber
hinausgehenden praktischen Tests behauptet. Bei sehr wenig Höhe kann vertikales
Scrollen nötig sein. Installer unsigniert; nur im vertrauenswürdigen privaten
Netzwerk verwenden (HTTP/WebSocket ohne Transportverschlüsselung).

## English

Responsive large/compact tablet layouts and new portrait/landscape phone UI.
Phones hide CPU/GPU/RAM metrics and output buttons. Hold Sound to select an
output; tap to mute/unmute. Hold Microphone to select an input as before.
Phones use a horizontal master fader and a relevant program/appearance Edit
menu. Up to five program rows without process IDs, global/individual fader
colors, tablet controls, PIN pairing and direct WebSocket commands are retained.

User-reported display checks passed on **iPad, iPhone 16 Pro and Samsung Galaxy
S21 Ultra**. **TABWEE T80 testing is pending.** No broader practical test coverage
is claimed. Very short viewports may scroll vertically. Unsigned installer;
use a trusted private network only.

## Installation / integrity

Install the new setup over 0.9.9; do not delete existing settings. Check the
startup option, then reload the mobile page and look for **v0.10.0 Beta**.
