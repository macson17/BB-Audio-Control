# BB Audio Control 1.0.0

First stable release of BB Audio Control.

## Highlights

- Responsive mixer for iPad, Android tablets, and smartphones
- Per-application volume, mute, and optional audio output
- Media controls with artwork, title, artist, previous, next, and play/pause
- Custom fader and background colors with brightness adjustment
- Shared custom background image for all paired devices
- GPU usage and temperature, including the Windows/D3DKMT path verified on an
  AMD Radeon 780M
- Local PIN pairing and immediate WebSocket control without a cloud service

## Installation

Download `BB-Audio-Control-Setup-v1.0.0.exe` below and run it on Windows 10
build 19041 or later, or Windows 11 x64. The installer can update an existing
BB Audio Control installation while retaining settings and the pairing code.

The installer is not digitally signed yet. Windows SmartScreen may display an
“Unknown publisher” warning. Only use the installer from this official release.
